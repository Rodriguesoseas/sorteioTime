# Sorteio Time 🎮

Um site simples desenvolvido para auxiliar jogadores de League of Legends na criação de partidas personalizadas de forma rápida e divertida.

## Funcionalidades

- Sorteio automático de equipes
- Distribuição aleatória de jogadores entre os times
- Sorteio de lanes (Top, Jungle, Mid, ADC e Suporte)
- Interface simples e intuitiva
- Funciona diretamente no navegador, sem necessidade de instalação

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivo

O projeto foi criado para facilitar a organização de partidas entre amigos, reduzindo o tempo gasto na definição manual de equipes e posições dentro do jogo.

## Como Utilizar

1. Acesse o site
2. Insira os nomes dos jogadores
3. Clique no botão de sorteio
4. Visualize os times e lanes gerados automaticamente
